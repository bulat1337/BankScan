# AlphaApi

Локальный bridge для чтения балансов из уже авторизованной вкладки `https://web.alfabank.ru/dashboard` через Chrome DevTools Protocol, без передачи логина, пароля, cookies или HTML дампа во внешние сервисы.

## Что делает проект

- подключается к уже открытому браузеру с `--remote-debugging-port`
- находит вкладку Альфа-Онлайн
- извлекает кандидаты на суммы и блоки балансов из DOM
- сохраняет результат в локальный JSON-файл

Проект предназначен для локального использования и ручной доработки селекторов под конкретный интерфейс банка.

## Требования

- Node.js `>=22`
- Google Chrome или Chromium
- отдельный браузерный профиль для банка

## Быстрый старт

1. Запустите отдельный Chrome с remote debugging:

```bash
open -na "Google Chrome" --args \
  --remote-debugging-port=9222 \
  --user-data-dir="$HOME/.alpha-debug-profile"
```

2. В этом окне откройте `https://web.alfabank.ru/dashboard` и войдите вручную.

3. Установите зависимости проекта:

```bash
npm install
```

4. Запустите сканирование:

```bash
npm run scan
```

Если нужно сначала перезагрузить вкладку:

```bash
npm run scan:reload
```

Результат будет записан в `out/alpha-dashboard-scan.json`.

## CLI

```bash
node scripts/alpha-dashboard-read.mjs [options]
```

Поддерживаемые опции:

- `--debug-url <url>`: адрес Chrome remote debugging, по умолчанию `http://127.0.0.1:9222`
- `--url-contains <text>`: фрагмент URL вкладки, по умолчанию `web.alfabank.ru/dashboard`
- `--out <path>`: путь к выходному JSON, по умолчанию `out/alpha-dashboard-scan.json`
- `--wait <ms>`: ожидание после `--reload`, по умолчанию `2500`
- `--reload`: перезагрузить вкладку перед чтением
- `--help`: показать справку

## Структура проекта

```text
.
├── package.json
├── README.md
├── scripts/
│   └── alpha-dashboard-read.mjs
└── out/
```

Каталог `out/` используется только для локальных результатов и не коммитится в Git.

## Безопасность

- не храните в репозитории JSON с реальными остатками
- не коммитьте cookies, токены и экспорт страницы
- используйте отдельный браузерный профиль только для этой задачи
- не держите `--remote-debugging-port` включённым постоянно

## Ограничения

- верстка интернет-банка может меняться и ломать эвристику поиска
- скрипт ищет кандидаты на баланс, а не гарантирует идеально стабильный селектор
- формат сумм и структура блоков могут отличаться для разных продуктов и аккаунтов

## Дальше можно добавить

- точное извлечение нужного баланса по стабильному селектору
- нормализацию нескольких счетов в единый `balances.json`
- периодический запуск по расписанию
- экспорт в Prometheus, CSV или Telegram-уведомления
